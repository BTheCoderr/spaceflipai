# SpaceFlip Pro Roadmap

This roadmap describes direction, not guaranteed dates.

## Shipped

- Expo / React Native client
- authenticated project intake and saved workspaces
- private property-photo storage with owner-scoped access
- structured upgrade plans and checklists
- server-side generation flow with provider fallbacks
- trusted account/workspace deletion path
- App Store submission/readiness documentation

## Improving

- real-device release QA
- generation reliability and error recovery
- private-media lifecycle cleanup
- accessibility and onboarding polish

## Exploring

- richer budget/contractor planning
- more flexible concept-generation modes
- export/share workflows that preserve private defaults

## Product boundary

Property photos and project data stay private by default. New AI providers must remain replaceable and must not become the source of truth for saved user work.
