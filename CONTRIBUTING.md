# Contributing to SpaceFlip Pro

SpaceFlip Pro is an Expo/React Native property-upgrade planning app backed by Supabase Auth, Postgres, Storage, RLS, Edge Functions, and server-side AI provider fallbacks.

Before a pull request, follow the README setup and run the existing CI/build checks. Changes to storage, RLS, generation, deletion, or project ownership should include focused verification.

Keep privileged work off-device and keep property media private by default.

A merged commit is not automatic approval for a production deployment.
